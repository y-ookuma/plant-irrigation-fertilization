# 🥒 キュウリ 潅水・施肥量計算機 (Cucumber Irrigation & Fertigation Calculator)

施設キュウリの養液土耕栽培における日射量・気象条件に応じた最適な潅水量および施肥量（液肥量・設備稼働時間）を算出・視覚化するWebアプリケーションです。

Open-Meteo APIと連携し、指定された潅水周期（1日〜7日）に応じた未来の気象予報データを取得して1日ごとに蒸散量を積算。データに基づいた高精度な潅水・施肥管理をサポートします[cite: 3]。

---

## 🌟 主な機能

* **☀️ 気象予報連動 & 期間積算機能**
  * Open-Meteo APIを利用し、指定された現在地の緯度・経度から未来の気象データ（全日射量・平均気温）を自動取得[cite: 3]。
  * 設定された潅水周期（1日/2日/3日/4日/5日/7日）に応じて未来の予報値を1日ごとに計算・積算[cite: 3]。

* **💧 潅水量 ＆ ⏱ 設備稼働時間の自動計算**
  * モンジ・サエキの群落消光理論とLAI（葉面積指数）に基づき、作物の受光量・蒸散量を算出[cite: 3]。
  * 設備の吐出流量（L/分）から、潅水に必要な具体的なタイマー稼働時間（分・秒）を算出[cite: 3]。

* **🧪 銘柄別 液肥必要量・希釈倍率計算**
  * 各種液肥銘柄（トミー液肥ブラック / トミー液肥グリーン / OK-F-1 など）に対応[cite: 3]。
  * 標準窒素濃度（N: 150ppm）を基準とした必要液肥量（L・kg）および希釈倍率を自動提示[cite: 3]。

* **🔄 養分収支バランス（給与 vs 果実持ち出し）ダイアグラム**
  * 果実の予定収穫量（kg）から果実による養分持ち出し量（N・P・K）を計算し、液肥給与量との差引バランスをSVGダイアグラムで視覚化[cite: 3]。

* **📊 管理サマリーのPNG画像出力 & JSON設定保存**
  * **PNG保存**: 計算結果・管理サマリー領域をワンクリックで高画質PNG画像としてダウンロード可能[cite: 3]。
  * **JSONインポート/エクスポート**: 栽培パラメータ（ハウス面積・株数・設備流量など）をファイルへ保存・復元[cite: 3]。

## 📖 用語解説

本アプリおよび農業現場で用いられる主要な専門用語の解説です[cite: 3]。

* **PAR (Photosynthetically Active Radiation / 光合成有効放射)**
  * 植物が光合成に利用できる波長域（400〜700nm）の太陽放射のこと。本アプリでは直達光と散乱光の比率を考慮して算出します[cite: 3]。

* **LAI (Leaf Area Index / 葉面積指数)**
  * 土地の表面積に対する、植物の葉の総面積の比率。例えばLAIが3.5の場合、1 $m^2$ の土地に対して3.5 $m^2$ の葉が存在することを意味し、群落の茂り具合（受光キャパシティ）を示します[cite: 3]。

* **消光係数 ($k$)**
  * 群落内を光が通過する際の減衰度合いを表す係数。キュウリ等の作物群落では一般的に $k = 0.7$ が用いられます[cite: 3]。

* **養液土耕 (Fertigation)**
  * 灌漑（かんがい）水に肥料を溶かして施用する栽培技術。水分と養分を同時に、作物の需要に合わせて高精度にコントロールします[cite: 3]。

* **蒸散 (Transpiration)**
  * 植物の葉の気孔から水分が水蒸気として大気中に放出される現象。日射量や気温に強く比例するため、潅水量の決定に不可欠な指標です[cite: 3]。

## 📐 計算式・アルゴリズムと学術的・公的出典

本アプリのロジックは、施設園芸学および植物生理学分野で確立された以下の学術モデル・指導基準に基づき構築されています[cite: 3]。

### 1. 光合成有効放射（PAR）の分離算定モデル

* **計算式**:
  $$\text{PAR}_{\text{直達}} = R_{s\text{直達}} \times 0.43$$
  $$\text{PAR}_{\text{散乱}} = R_{s\text{散乱}} \times 0.57$$
* **解説**: 太陽放射（短波放射 $R_s$）の分光組成特性に基づき、直達光成分の43%、散乱光成分の57%がPAR領域に含まれるという光学特性を反映しています[cite: 3]。

### 2. 群落受光モデル（光吸収の推計）

* **計算式**:
  $$A_{\text{ratio}} = 1 - e^{-0.7 \times \text{LAI}}$$
  $$\text{吸収積算放射量} = \text{全天短波放射} \times A_{\text{ratio}}$$
* **出典**: **モンシ・サエキの群落消光理論（Monsi & Saeki, 1953）**[cite: 3]
* **解説**: ランベルト・ベールの法則を植物群落に応用したもので、LAIと消光係数 $k=0.7$ から、群落全体がどれだけの光エネルギーを捕捉・吸収しているかを正確に推計します[cite: 3]。

### 3. 蒸散量および気象補正モデル

* **計算式**:
  $$\text{基本蒸散量} = \text{吸収放射エネルギー} \times 0.35\,\text{L/m}^2/\text{MJ}$$
  * ※気温補正: 平均気温が $25^\circ\text{C}$ を超える場合、$1^\circ\text{C}$ あたり $+2\%$ 増量[cite: 3]
  * ※湿度補正: 平均湿度が $50\%$ を下回る場合、$1\%$ あたり $+0.5\%$ 増量[cite: 3]
* **出典**: **FAO-56 基準蒸発散モデル（Penman-Monteith式）** の概念を簡易応用[cite: 3]
* **解説**: 吸収された光エネルギーに対する標準的な水分蒸散量をベースにしつつ、乾燥ストレスや高気温による蒸散亢進を動的に補正します[cite: 3]。

### 4. 施肥基準と果実持ち出し量算出

* **計算式**:
  $$\text{必要窒素量(g)} = \text{総給水量(L)} \times 0.15\,\text{g/L}$$
  $$\text{果実乾物重} = \text{収穫量(kg)} \times 0.04$$
* **出典**: **農研機構（NARO）等の施設キュウリ養液土耕栽培マニュアル**[cite: 3]
* **解説**: 給液中の標準窒素濃度を $150\,\text{ppm}$（$0.15\,\text{g/L}$）に設定。また、キュウリ果実の乾物率（4.0%）および乾物中の主要成分含有率（N: 3.0%, P: 1.0%, K: 4.5%）から、収穫によって圃場外へ持ち出される養分量を正確に差し引きます[cite: 3]。
* **💡 収穫量が0（果実持ち出しが0）の場合の液肥計算について**: 
  アプリ内の肥料必要量は、植物が生育するために必要な標準要求量（日射量や総株数ベース）から算出されています。入力項目の「予定収穫量 (`harvestKg`)」は下部の養分収支バランス（給与量と持ち出し量の差）を表示するためのものであり、収穫量を0に設定しても給与肥料の計算値は変動しません。生育期間中は果実がなっていない時期（収穫前など）であっても、植物体（根・茎・葉）の維持・成長やLAIの維持のために養分が不可欠であるため、収穫ゼロの期間であっても生育ステージに応じた液肥管理を行う前提で計算されています。収穫前等で肥料を控えめにしたい場合は、栽培パラメータの「LAI」を小さめに調整してください。

## 🌐 使用している外部API

* **Open-Meteo Weather API**
  * **用途**: 緯度・経度を指定したピンポイントの未来気象予報（直達日射量、散乱日射量、平均気温、平均湿度）の取得[cite: 3]。
  * **特徴**: 商用・非商用問わず登録不要で利用可能なオープンかつ高精度な気象データAPIです[cite: 3]。

## 🚀 使い方・操作手順

1. **位置情報の指定**: 「現在地から緯度経度を取得」ボタンを押すか、圃場の緯度経度を入力[cite: 3]。
2. **栽培パラメータの設定**: ハウス面積、総株数、設備潅水量（L/分）、潅水周期、LAI、使用液肥銘柄、予定収穫量を入力[cite: 3]。
3. **計算実行**: 「🚀 計算実行」を押すと、総潅水量、必要液肥量、**ポンプ稼働時間（分・秒）**、および詳細なビジュアルサマリーが即座に表示されます[cite: 3]。
4. **保存・共有**: 「🖼 サマリーをPNG保存」で画像として出力するか、「JSON保存」で設定をエクスポート可能です[cite: 3]。

---

## ⚠️ 免責事項・注意事項

* 本アプリの計算結果は、学術モデルと気象予報に基づいた理論計算値（目安）です。実際の管理では、土壌や培地の水分状態、根の張りの健康度、ハウス内の実際の環境、作物の草勢を必ず観察し、適宜調整を行ってください[cite: 3]。
* 外部の無料気象API（Open-Meteo）を利用しているため、ネットワーク環境がない場合はデフォルト値でフォールバック計算が行われます[cite: 3]。
