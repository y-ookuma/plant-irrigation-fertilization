# 🥒 キュウリ 潅水・施肥量計算機 (Cucumber Irrigation & Fertigation Calculator)

施設キュウリの養液土耕栽培における**日射量・気象条件に応じた最適な潅水量および施肥量（液肥量・設備稼働時間）**を算出・視覚化するWebアプリケーションです。

Open-Meteo APIと連携し、指定された潅水周期（1日〜7日）に応じた未来の気象予報データを取得して1日ごとに蒸散量を積算。データに基づいた高精度な潅水・施肥管理をサポートします。

---

## 🌟 主な機能

* **☀️ 気象予報連動 & 期間積算機能**
  * Open-Meteo APIを利用し、指定された現在地の緯度・経度から未来の気象データ（全日射量・平均気温）を自動取得。
  * 設定された**潅水周期（1日/2日/3日/4日/5日/7日）**に応じて未来の予報値を1日ごとに計算・積算。
* **💧 潅水量 ＆ ⏱ 設備稼働時間の自動計算**
  * モンジ・サエキの群落消光理論とLAI（葉面積指数）に基づき、作物の受光量・蒸散量を算出。
  * 設備の吐出流量（L/分）から、潅水に必要な具体的なタイマー稼働時間（分・秒）を算出。
* **🧪 銘柄別 液肥必要量・希釈倍率計算**
  * 各種液肥銘柄（トミー液肥ブラック / トミー液肥グリーン / OK-F-1 など）に対応。
  * 標準窒素濃度（N: 150ppm）を基準とした必要液肥量（L・kg）および希釈倍率を自動提示。
* **🔄 養分収支バランス（給与 vs 果実持ち出し）ダイアグラム**
  * 果実の予定収穫量（kg）から果実による養分持ち出し量（N・P・K）を計算し、液肥給与量との差引バランスをSVGダイアグラムで視覚化。
* **📊 管理サマリーのPNG画像出力 & JSON設定保存**
  * **PNG保存**: 計算結果・管理サマリー領域をワンクリックで高画質PNG画像としてダウンロード可能。
  * **JSONインポート/エクスポート**: 栽培パラメータ（ハウス面積・株数・設備流量など）をファイルへ保存・復元。

## 📖 詳細な使い方

### 1. アプリの起動
* `index.html` をお使いのWebブラウザ（Google Chrome, Microsoft Edge, Safari等）で開きます。

### 2. 各種パラメータの入力
1. **位置情報設定**: 
   * 「現在地から緯度経度を取得」ボタンを押すか、圃場（ハウス）の緯度・経度を直接入力します。
2. **栽培パラメータ**:
   * **ハウス面積 (m²)** と **総株数 (本)** を入力します（株数密度本/m²は自動計算されます）。
   * **設備潅水量 (L/分)**: 送水ポンプや電磁弁1ブロックあたり等、実際に1分間でハウス全体に給水される流量を入力します。
   * **潅水周期 (日)**: 次回の潅水までに何日分の水・肥料を与えるかを選択します（例: 3日ごと）。
   * **LAI (葉面積指数)**: 現在の作物の生育ステージに合わせて指定します（育苗期〜定着期: 0.5〜1.0 / ピーク収穫期: 3.0〜4.5）。
   * **使用液肥銘柄**: 使用する液肥の種類を選択します。
   * **予定収穫量 (kg)**: 該当期間内に収穫予定の果実重を入力します（任意・養分持ち出し量の計算に使用）。
3. **気象パラメータ (手動指定の場合)**:
   * 空欄の場合は自動的にOpen-Meteoから予報を取得します。特定の環境（ハウス内高温など）をシミュレーションしたい場合は数値を入れることで優先適用されます。

### 3. 計算とサマリー確認・保存
1. **「🚀 計算実行」** をクリックします。
2. 画面下部に計算対象期間（例: `2026/09/07 〜 2026/09/09`）と対象日数、総潅水量・必要液肥量・**ポンプ稼働時間（分・秒）**が表示されます。
3. **「🖼 サマリーをPNG保存」** ボタンを押すと、計算結果カード全体が画像ファイルとしてダウンロードされます。現場作業への指示書や記録用としてご活用ください。
4. 設定したハウス条件は「💾 設定を出力 (エクスポート)」からJSON保存しておくと、次回以降「設定を読み込み」から瞬時に復元できます。

## ⚠️ 使用上の注意事項

* **計算結果はあくまで推計値（目安）です**
  * 本アプリで算出される潅水量および液肥量は、学術モデルと気象予報に基づいた**理論計算値**です。実際の管理では、培地（土壌・培地資材）の水分状態、根の張り具合、ハウス内の実際の温湿度、作物の草勢（勢い）を観察し、適宜微調整を行ってください。
* **Open-Meteo API（気象予報）に関する注意**
  * 気象データは外部の無料API（Open-Meteo）から取得しているため、実際の圃場環境（ハウス内の加温・遮光・換気状態）と外気予報値との間に乖離が生じる場合があります。
  * インターネット接続がない環境ではデフォルト値（日射量: 15.0 MJ/m²、気温: 25.0 ℃）で計算が実行されます。
* **設備流量（L/分）の設定精度**
  * 稼働時間（分・秒）の算出は「設備潅水量 (L/分)」の入力値に依存します。水圧変動やノズルの詰まり等で実際の吐出量が異なる場合、給水量に誤差が出ますので定期的な流量校正（実測）を推奨します。
* **免責事項**
  * 本アプリの計算結果に基づいて行われた栽培管理業務、およびそれによって生じた収量低下・生育障害・設備トラブル等の直接的・間接的損害について、開発者は一切の責任を負いかねます。あらかじめご了承ください。

## 📘 学術・技術的根拠

本計算機は、施設園芸および植物生理学分野で確立された以下の学術モデル・指導基準に基づきアルゴリズムを構築しています。

1. **群落受光モデル (光吸収推計)**
   * モンシ・サエキの消光理論（Monsi & Saeki, 1953）に準拠。
   * 消光係数 $k = 0.7$ と LAI（葉面積指数）から群落受光率 $\left(1 - e^{-k \cdot \text{LAI}}\right)$ を算出。
2. **蒸散・気象補正**
   * FAO-56 基準蒸発散モデル（Penman-Monteith式）の概念を応用。
   * 受光エネルギー $1\text{ MJ/m}^2$ あたり $0.35\text{ L/m}^2$ を基準蒸散量とし、気温（25℃超過時 +2%/℃）および湿度（50%未満時 +0.5%/1%低下）による自動補正を実行。
3. **施肥基準 & 養分持ち出し**
   * 農研機構（NARO）等の養液土耕栽培マニュアルに基づき、給液中の標準窒素濃度を **150 ppm** に設定。
   * キュウリ果実の乾物率 **4.0%**、乾物中養分含有率（N: 3.0%, P: 1.0%, K: 4.5%）より持ち出し成分量を換算。
