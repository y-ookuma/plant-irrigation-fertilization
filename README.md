# 🥒 キュウリ 潅水・施肥量計算機 (Cucumber Irrigation & Fertigation Calculator)

施設キュウリの養液土耕栽培における日射量・気象条件に応じた最適な潅水量および施肥量（液肥量・設備稼働時間）を算出・視覚化するWebアプリケーションです。

Open-Meteo APIと連携し、指定された潅水周期（1日〜10日）に応じた未来の気象予報データを取得して1日ごとに蒸散量を積算。データに基づいた高精度な潅水・施肥管理をサポートします。

------

## 🌟 主な機能

- **☀️ 気象予報連動 & 期間積算機能**
  - Open-Meteo APIを利用し、指定された現在地の緯度・経度から未来の気象データ（全天日射量・平均気温・平均湿度、および時間別の直達日射量・散乱日射量）を自動取得。
  - 設定された潅水周期（1〜10日）に応じて未来の予報値を1日ごとに計算・積算。
  - 液肥使用量などと表示単位を揃えるため、全天日射量・PAR（光合成有効放射）・吸収PAR・群落蒸散量は「期間（選択した日数分）の積算値」を基本に表示し、参考として1日あたりの平均値も併記します。
- **☀️ 直達光・散乱光分離によるPAR高精度算定**
  - 時間別の直達日射量・散乱日射量データを日単位に積算し、直達光成分（43%）・散乱光成分（57%）それぞれに固有の分光特性係数を乗じてPARを算出する「分離モデル」を採用。
  - 気象データを手動入力した場合や、Open-Meteo側で直達/散乱データが取得できない日は、その日に限り簡易係数（全天日射 × 0.48）による近似値に自動でフォールバックします。どちらのモデルが使用されたかは、計算結果の「適用環境・設備データ一覧」に明示されます。
- **💧 潅水量 ＆ ⏱ 設備稼働時間の自動計算**
  - モンジ・サエキの群落消光理論とLAI（葉面積指数）に基づき、作物の受光量・蒸散量を算出。
  - 設備の吐出流量（L/分）から、潅水に必要な具体的なタイマー稼働時間（分・秒）を算出。
- **🧪 銘柄別 液肥必要量・希釈倍率計算**
  - 各種液肥銘柄（トミー液肥ブラック / トミー液肥グリーン / OK-F-1 など）に対応。
  - 標準窒素濃度（N: 150ppm）を基準とした必要液肥量（L・kg）および希釈倍率を自動提示。
- **🔄 養分収支バランス（給与 vs 果実持ち出し）ダイアグラム**
  - 果実の予定収穫量（kg）から果実による養分持ち出し量（N・P・K）を計算し、液肥給与量との差引バランスをSVGダイアグラムで視覚化。
  - 「給液中の養成分バランス目安」の棒グラフは、N・P・Kのうち最も量の多い成分を100%とした相対比でバーの長さを算出し、常に実際の数値と一致した表示になります。
- **📊 適用環境・設備データ一覧（期間平均値 ＆ 期間積算値）**
  - 短波放射（Rs）、直達日射 / 散乱日射、PAR、吸収PAR、群落蒸散量について「期間平均値」と「期間積算値」の両方を一覧表示し、潅水日数を変更した際の総量把握を容易にします。
  - PARの算定にどちらのモデル（分離モデル／簡易係数フォールバック）が使用されたかも表示します。
- **📊 管理サマリーのPNG画像出力 & JSON設定保存**
  - **PNG保存**: 計算結果・管理サマリー領域をワンクリックで高画質PNG画像としてダウンロード可能。
  - **JSONインポート/エクスポート**: 栽培パラメータ（ハウス面積・株数・設備流量など）をファイルへ保存・復元。

## 📖 用語解説

本アプリおよび農業現場で用いられる主要な専門用語の解説です。

- **PAR (Photosynthetically Active Radiation / 光合成有効放射)**
  - 植物が光合成に利用できる波長域（400〜700nm）の太陽放射のこと。本アプリでは、直達日射・散乱日射をそれぞれ分離して算出する「分離モデル」を基本とし、データが無い場合のみ全天日射（Rs）に簡易換算係数（0.48）を乗じる方法にフォールバックします。
- **群落光吸収率 / A(ratio)**
  - 群落（葉の集合体）に入射したPARのうち、葉に遮られて実際に吸収される割合（0〜1、％表示では0〜100%）。LAIが大きく葉が茂るほど1（100%）に近づきます。
- **吸収PAR（吸収放射エネルギー）**
  - PARのうち、実際に群落（葉）に吸収されたエネルギー量（単位: MJ/m²）。「PAR × 群落光吸収率 A(ratio)」で求められ、蒸散量計算の基礎となる値です。全天日射（Rs）そのものではない点に注意してください。
- **LAI (Leaf Area Index / 葉面積指数)**
  - 土地の表面積に対する、植物の葉の総面積の比率。例えばLAIが3.5の場合、1 m² の土地に対して 3.5 m² の葉が存在することを意味し、群落の茂り具合（受光キャパシティ）を示します。
- **消光係数 (k)**
  - 群落内を光が通過する際の減衰度合いを表す係数。キュウリ等の作物群落では一般的に k = 0.7 が用いられます。
- **養液土耕 (Fertigation)**
  - 灌漑（かんがい）水に肥料を溶かして施用する栽培技術。水分と養分を同時に、作物の需要に合わせて高精度にコントロールします。
- **蒸散 (Transpiration)**
  - 植物の葉の気孔から水分が水蒸気として大気中に放出される現象。日射量や気温に強く比例するため、潅水量の決定に不可欠な指標です。

## 📐 計算式・アルゴリズムと学術的・公的出典

本アプリのロジックは、施設園芸学および植物生理学分野で確立された以下の学術モデル・指導基準に基づき構築されています。

### 1. 光合成有効放射（PAR）の分離算定モデル

- **計算式**:
  - PAR = 直達日射 × 0.43 ＋ 散乱日射 × 0.57
  - （フォールバック時のみ）PAR = Rs（全天日射・短波放射） × 0.48
- **解説**: 太陽放射（短波放射 Rs）のうち、光合成に利用可能な波長域（PAR）が占める割合は、一般に直達光成分で約43%、散乱光成分で約57%とされています。Open-Meteo APIから取得する**時間別（hourly）の直達日射量・散乱日射量**を日単位に積算（MJ/m²/日へ変換）し、それぞれに固有の係数を乗じて日ごとにPARを算出しています。
- **💡 フォールバックについて**: 気象データを手動入力した場合（直達/散乱を個別に入力する項目は無いため）や、Open-Meteo側で当該日の直達/散乱データが欠測している場合は、その日に限り、直達光・散乱光の中間的な値である**単一の簡易換算係数 0.48（Rs × 0.48）**で近似計算します。どちらのモデルで算出されたかは、計算結果の「適用環境・設備データ一覧」＞「PAR」行に表示される算定モデル名でご確認いただけます。

### 2. 群落受光モデル（光吸収の推計）

- **計算式**:
  - A(ratio) = 1 - e^(-0.7 × LAI)
  - 吸収PAR = PAR（光合成有効放射） × A(ratio)
- **出典**: **モンシ・サエキの群落消光理論（Monsi & Saeki, 1953）**
- **解説**: ランベルト・ベールの法則を植物群落に応用したもので、LAIと消光係数 k = 0.7 から、群落全体がどれだけの光エネルギーを捕捉・吸収しているかを正確に推計します。
- **💡 A(ratio) が具体的に示すもの**: A(ratio) は「**群落光吸収率（群落受光率）**」で、群落（葉の集合体）に入射した光のうち、葉に遮られて吸収される割合を 0〜1（％表示では 0〜100%）で表す無次元の比率です。LAI（葉の茂り具合）が大きいほど 1 に近づき、群落最上部から下層まで光がほぼ吸収し尽くされることを意味します。本アプリでは、この A(ratio) を PAR（光合成有効放射）に乗じることで「群落が実際に光合成のために吸収したPARエネルギー（吸収PAR）」を算出しています。

### 3. 蒸散量および気象補正モデル

- **計算式**:
  - 基本蒸散量 = 吸収放射エネルギー × 0.35 L/m²/MJ
  - ※気温補正: 平均気温が 25℃ を超える場合、1℃ あたり +2% 増量
  - ※湿度補正: 平均湿度が 50% を下回る場合、1% あたり +0.5% 増量
- **出典**: **FAO-56 基準蒸発散モデル（Penman-Monteith式）** の概念を簡易応用
- **解説**: 吸収された光エネルギーに対する標準的な水分蒸散量をベースにしつつ、乾燥ストレスや高気温による蒸散亢進を動的に補正します。
- **💡 「吸収放射エネルギー」が具体的に示すもの**: ここでの「吸収放射エネルギー」は、全天日射（Rs）そのものではなく、上記2で算出した「**吸収PAR（群落が実際に吸収した光合成有効放射のエネルギー量、単位: MJ/m²）**」を指します。つまり、太陽から降り注ぐ全天日射のうち、①上記1の分離モデル（またはフォールバック時は簡易係数0.48）でPARの波長成分に絞り込み、②さらに群落のLAI・消光係数に基づく吸収率 A(ratio) を乗じて実際に葉が捉えたエネルギー分だけを取り出したうえで、蒸散量の計算に用いています。

### 4. 施肥基準と果実持ち出し量算出

- **計算式**:
  - 必要窒素量(g) = 総給水量(L) × 0.15 g/L
  - 果実乾物重 = 収穫量(kg) × 0.04
- **出典**: **農研機構（NARO）等の施設キュウリ養液土耕栽培マニュアル**
- **解説**: 給液中の標準窒素濃度を 150 ppm（0.15 g/L）に設定。また、キュウリ果実の乾物率（4.0%）および乾物中の主要成分含有率（N: 3.0%, P: 1.0%, K: 4.5%）から、収穫によって圃場外へ持ち出される養分量を正確に差し引きます。
- **💡 収穫量が0（果実持ち出しが0）の場合の液肥計算について**: 
  アプリ内の肥料必要量は、植物が生育するために必要な標準要求量（日射量や総株数ベース）から算出されています。入力項目の「予定収穫量 (`harvestKg`)」は下部の養分収支バランス（給与量と持ち出し量の差）を表示するためのものであり、収穫量を0に設定しても給与肥料の計算値は変動しません。生育期間中は果実がなっていない時期（収穫前など）であっても、植物体（根・茎・葉）の維持・成長やLAIの維持のために養分が不可欠であるため、収穫ゼロの期間であっても生育ステージに応じた液肥管理を行う前提で計算されています。収穫前等で肥料を控えめにしたい場合は、栽培パラメータの「LAI」を小さめに調整してください。

## 🌐 使用している外部API

- **Open-Meteo Weather API**
  - **用途**: 緯度・経度を指定したピンポイントの未来気象予報を取得。
    - 日別（daily）: 全天日射量（短波放射量）、平均気温、平均湿度
    - 時間別（hourly）: 直達日射量（direct_radiation）、散乱日射量（diffuse_radiation）※PARの分離モデル算定用に、日単位へ積算・変換して使用
  - **特徴**: 商用・非商用問わず登録不要で利用可能なオープンかつ高精度な気象データAPIです。

## 🚀 使い方・操作手順

1. **位置情報の指定**: 「現在地から緯度経度を取得」ボタンを押すか、圃場の緯度経度を入力。
2. **栽培パラメータの設定**: ハウス面積、総株数、設備潅水量（L/分）、潅水周期、LAI、使用液肥銘柄、予定収穫量を入力。
3. **計算実行**: 「🚀 計算実行」を押すと、総潅水量、必要液肥量、**ポンプ稼働時間（分・秒）**、および詳細なビジュアルサマリーが即座に表示されます。
4. **保存・共有**: 「🖼 サマリーをPNG保存」で画像として出力するか、「JSON保存」で設定をエクスポート可能です。

## ❓ よくあるご質問 (Q&A)

* **Q1. 期間（「3日ごと」「7日ごと」など）を変えると、表示される数値はどう変わりますか？**
* **A:** 画面に表示される水・肥料・日射量・PAR・群落蒸散量の数値は、いずれも選択した**日数分の合計（積算）量**（3日分なら3日間の総計、7日分なら7日間の総計）として表示を統一しています。1日あたりの平均値も参考として併記していますので、毎日の潅水に分割する場合は、そちらの平均値、または合計値を日数で割った値を1回あたりの目安にしてください。

* **Q1-2. 「適用環境・設備データ一覧」に「期間平均値」と「期間積算値」が両方表示されているのはなぜですか？**
* **A:** 短波放射・直達日射/散乱日射・PAR・吸収PAR・群落蒸散量は、日々の環境条件の目安として「期間平均値（1日あたり）」を、資材計算や総量把握の目安として「期間積算値（選択した日数分の合計）」を、それぞれ別の視点として併記しています。液肥使用量や潅水量は元々期間の合計値のみで表示されるため、両者を見比べる際は「期間積算値」側を基準にしてください。

* **Q1-3. 「給液中の養成分バランス目安」の棒グラフは何を基準に長さが決まっていますか？**
* **A:** N（窒素）・P（リン酸）・K（カリウム）のうち、給液量が最も多い成分を100%として、他の成分はその相対比でバーの長さを表示しています。あくまで3成分間の量のバランスを直感的に把握するための相対表示であり、絶対的な充足度や目標値との比較を示すものではありません。正確な量は各バー横のkg数値をご確認ください。

* **Q1-4. PARの計算に「直達43%/散乱57%の分離モデル」と「簡易係数0.48」の2種類があるのはなぜですか？どちらが使われているか分かりますか？**
* **A:** 本アプリは基本的に、Open-Meteoから取得した時間別の直達日射量・散乱日射量データを日単位に積算し、直達光成分に0.43、散乱光成分に0.57を乗じる「分離モデル」でPARを算出します。ただし、①気象データを画面上で手動入力した場合（直達/散乱を個別入力する項目が無いため）や、②Open-Meteo側でその日の直達/散乱データが欠測している場合は、その日に限り全天日射（Rs）に簡易係数0.48を乗じる近似計算にフォールバックします。どちらの方式が使われたかは、計算結果の「適用環境・設備データ一覧」＞「PAR」行の「算定モデル」表示でご確認いただけます。

* **Q2. 肥料の表示で「kg」と「L」のどちらを信じればいいですか？**
* **A:** 粉末肥料（OK-F-1など）の場合は「kg（キログラム）」の数値を見て、秤で正確に重さを量ってください。液体肥料（トミー液肥シリーズなど）の場合は「L（リットル）」の数値を見て、計量カップやポンプで体積を測って投入するのが実務的です。

* **Q3. 気象データを手動入力せず空白にすると、どうやって計算されますか？**
* **A:** 手動入力欄を空欄にしておくと、Open-Meteo APIを通じて、指定された緯度・経度の現地の気象予報・実績データ（短波放射量・平均気温・湿度）を自動取得し、その値をもとにリアルタイムで高精度な計算を行います。

* **Q4. 収穫量（kg）を入力する欄がありますが、これは何の計算に使われますか？**
* **A:** キュウリの果実が収穫される際に、ハウス外へと持ち出される養分量（窒素・リン酸・カリウム）を正確に逆算するために使用します。これにより、ただ肥料をあげるだけでなく、果実の収穫による養分のマイナス分相殺を含めた、より実践的な養分収支バランスが算出されます。

* **Q5. 「葉面積指数 (LAI)」はどのように決めればいいですか？**
* **A:** 作物の生育ステージに合わせて設定してください。目安として、苗期は 0.5〜1.0、通常の生育期は 2.0〜3.0、繁茂した最盛期は 3.5〜5.0 程度を入力します。受光率や蒸散量の計算に直接影響します。

## ⚠️ 免責事項・注意事項

- 本アプリの計算結果は、学術モデルと気象予報に基づいた理論計算値（目安）です。実際の管理では、土壌や培地の水分状態、根の張りの健康度、ハウス内の実際の環境、作物の草勢を必ず観察し、適宜調整を行ってください。
- 外部の無料気象API（Open-Meteo）を利用しているため、ネットワーク環境がない場合はデフォルト値でフォールバック計算が行われます。
